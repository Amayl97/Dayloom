# 🌿 Dayloom — Less Scrolling, More Living

**What if AI didn't ask for more of your screen time, but helped you spend less of it?**

Dayloom is a web application built for the [Hacktoberfest Open-Source AI Challenge — Week 1: Touch Grass](https://dev.to/challenges/hacktoberfest-week1-2026-10-05).

In a world filled with endless scrolling, short-form videos, and constant digital stimulation, stepping away from our devices can be harder than it sounds. Dayloom uses open-source AI to inspire people to take a break from their screens, enjoy small real-world experiences, and turn those moments into memories worth keeping.

Instead of encouraging more screen time, Dayloom encourages you to go outside, slow down, and appreciate the little things around you.

## ✨ Features

- **🌱 AI-Powered Daily Activities:** Generate five fun, peaceful, and achievable offline activities using Gemma 3 4B.
- **💬 Daily Motivational Message:** Receive an encouraging message to inspire your day.
- **📸 Capture Your Moments:** Upload photos from your offline adventures and preview or replace them.
- **🎞️ Personalized Memory Cards:** Transform your photos into a visually styled collage featuring the date and a motivational message.
- **⬇️ Download and Share:** Download your memory card as an image and share your daily moments with friends.
- **💾 Saved Progress:** Keep your activity and photo progress available across page refreshes.
- **🎨 Cozy, Playful Design:** A warm, nostalgic aesthetic inspired by creative journaling and Pinterest-style photo collages.

## 💡 Why Dayloom?

We spend so much of our lives consuming digital content that ordinary offline experiences can sometimes feel less exciting in comparison.

Dayloom explores a different use of technology: **what if AI inspired us to spend less time using technology?**

The application suggests small activities that encourage users to experience the world around them, whether that means enjoying a favorite drink without distractions, taking a walk, or noticing something beautiful in the sky.

### Why memory cards?

My generation loves creating aesthetic collages, collecting memories, and sharing visual stories on platforms like Pinterest. I wanted to bring that familiar creative experience into everyday offline life.

After completing their activities, users can turn their photographs into a personalized daily memory card. The collage makes their experience tangible, creative, and shareable.

The idea is simple: rather than making screen time itself the reward, Dayloom makes the real-world experience the starting point and the memory the reward.

## 🤖 Open-Source AI at the Core

Dayloom uses **Gemma 3 4B**, an open-weight model, through [Ollama](https://ollama.com/).

The model generates the daily activities and motivational message that power the experience. Running the model locally lets me experiment with AI-powered features without relying on a proprietary, hosted LLM API for this generation workflow.

The application handles uploaded photographs separately. The images are used to create the memory collage; they are not sent to Gemma for image analysis. The collage itself is generated by the application.

This project is an exploration of how open-weight AI can be used for something beyond generating more digital content: encouraging people to reconnect with the world beyond their screens.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js and npm](https://nodejs.org/)
- [Ollama](https://ollama.com/)

### 1. Clone the repository

```bash
git clone 
cd dayloom
```

Replace the repository URL with your actual GitHub repository URL. If your local folder or repository uses a different name, adjust the directory accordingly.

### 2. Download the Gemma model

Start Ollama and run:

```bash
ollama pull gemma3:4b
```

Verify that the model is available:

```bash
ollama list
```

### 3. Install dependencies

From the project directory, run:

```bash
npm install
```

### 4. Start the application

Start the frontend using:

```bash
npm run dev
```

Run the backend according to the project's configured startup command and ensure Ollama is running with the required model. The frontend and backend must both be available for AI-powered activity generation.

**Note:** Local model inference requires a compatible environment and sufficient system resources. The application is not guaranteed to work without internet for every feature or dependency.

## 🎬 How It Works

1. **Generate:** Ask Dayloom to generate five offline activities and a motivational message using Gemma.
2. **Explore:** Choose activities and spend time experiencing them away from your screen.
3. **Capture:** Upload photographs of the moments you want to remember.
4. **Create:** Generate a personalized collage with your photographs, the date, and a motivational message.
5. **Keep and Share:** Download your memory card and share it with friends.
